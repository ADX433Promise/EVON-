# EVON Web

هذا المشروع موقع بسيط لرفع الملفات وعرض رابط تنزيل تجريبي بنمط داكن وألوان سوداء وبنفسجية.

## نشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملفات المشروع إليه.
3. اذهب إلى الإعدادات → Pages.
4. اختر الفرع main أو master ومجلد root.
5. احفظ وانشر.

## ملاحظات

هذا الإصدار مناسب للنشر على GitHub Pages كواجهة أمامية فقط. إذا أردت رفع ملف حقيقي مع حد أقصى لعدد الفتحات، فستحتاج خادم Backend مثل Netlify Functions أو Render أو Vercel.
